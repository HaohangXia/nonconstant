# Contract amendments

The initial project boundaries were frozen deliberately. A change to those boundaries is
recorded here instead of being silently rewritten in the original contract.

|---|---|

| [`A004`](A004-base-from-config.md) | Required the comparison base to come from protected configuration. |
| [`A005`](A005-vendor-as-submodule.md) | Converted the spec-kit dependency to a pinned Git submodule. |
| [`A006`](A006-distributability-field.md) | Made distributability an explicit gate attribute. |
| [`A007`](A007-reorder-phase10-before-8.md) | Separated phase identity from execution order. |
