# 审计记录导读

> 如果本目录任何文件与 [`01-PLAN.md`](01-PLAN.md) 冲突，以计划为准。
> 编号 04–15 的文件是过程记录，不自动代表当前结论。

往返审计中有一部分结论后来已被推翻。请先读 [`STATUS.md`](STATUS.md)，再读
[`01-PLAN.md`](01-PLAN.md)；单独打开一份历史回复，可能会重建出已经过时的方案。

| 文件 | 用途 | 权威性 |
|---|---|---|
| [`STATUS.md`](STATUS.md) | 当前状态、已完成阶段与未决事项。 | 当前索引；注明的部分有机器检查。 |
| [`01-PLAN.md`](01-PLAN.md) | 设计、阶段计划与已经接受的结论反转。 | 当前计划的唯一主真源。 |
| [`03-LEDGER.md`](03-LEDGER.md) | 跨 session 观察、被否决方案与原意图重建。 | 当前证据台账。 |
| [`18-PROTOCOL.md`](18-PROTOCOL.md) | 随证据订正的操作规则。 | 当前协议；理由保留在台账中。 |
| [`16-DECISIONS.md`](16-DECISIONS.md) | 决策理由。 | 历史文件，但对已记录决策仍具权威性。 |
| [`17-DEVLOOP-DECISIONS.md`](17-DEVLOOP-DECISIONS.md) | DevLoop 一侧的审计决策。 | 历史决策记录。 |
| `14-*` / `15-*` | 编排层核验与 hook 靶场观察。 | 对记录时提交有效的实测结果。 |
| `04-*`、`06-*`、`08-*` | 往返审计文档。 | 仅为历史过程，必须回到计划复核。 |

编号 05、07、09、10、11、12、13 的回复有意不保存在本仓库；被接受的结论已经折入计划。
不要因为编号不连续而创建空白占位文件。
